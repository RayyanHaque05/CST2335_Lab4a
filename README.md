## Description
A To Do list Android application using a `ListView` and a custom `BaseAdapter`:
- Dynamic item addition with cleared `EditText` on submit.
- Urgent task flagging via `SwitchCompat`, rendering urgent rows with a red background and white text.
- Long-click row selection triggering an `AlertDialog` displaying row index and confirming deletion.
- Full localization in English and French.
